# Transistor - Level Implementation and Validation of a Switching-Activity Optimized Reversible Full Adder 

## Overview
This project presents the transistor-level CMOS implementation and validation of a switching-activity optimized reversible full adder using GPDK 90 nm technology and Cadence Virtuoso. In this project not Implemented a New Design and Validates a Design present in Journal of VLSI Circuits and Systems, vol. 6, no. 1, pp. 7–18, 2024, 
doi:10.31838/jvcs/06.01.02 by the Authors of C. Pakkiraiah and R. V. S. Satyanarayana.

## Objectives
- Reduce switching activity
- Improve power efficiency
- Validate reversible logic at transistor level
- Correct NG gate functionality issues

## Tools Used
- Cadence Virtuoso
- GPDK 90 nm CMOS Technology

## Key Features
- Reversible Full Adder Design
- FG, TG, and Corrected NG Gates
- Transistor-Level Validation
- Power and Delay Analysis

## Results
- Average Power: 3.168 µW
- Worst Case Delay: 197.5 ps
